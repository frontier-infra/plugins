# Frontier Infra plugin privacy policy

Effective date: 2026-08-06

Public URL: `https://frontierinfra.org/privacy`

The Frontier Infra plugin is a skills-only package containing instructions, references, and templates. The plugin itself does not operate a hosted service, create an account, collect personal information, receive conversation content, or receive credentials.

The plugin may guide a user's AI agent to inspect or modify files and run tools in environments the user controls. Those actions remain subject to the host product's permissions and the policies of any tool or service the user separately chooses. Frontier Infra does not receive that data through this plugin.

If a future version adds hosted tools, authentication, telemetry, or an MCP server, this policy must be updated before that version is published to explain data categories, purposes, recipients, retention, and user controls.

Support: `https://frontierinfra.org/support`

Publisher: Jason Kent Brashear, verified individual developer. Frontier Infra is the project and product name.

This policy describes the skills-only release. It must be reviewed and updated before any release adds hosted tools, authentication, telemetry, signing, or remote dispatch.
