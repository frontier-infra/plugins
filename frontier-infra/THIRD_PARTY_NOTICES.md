# Third-party notices and provenance

This plugin is a skills-only Frontier Infra package. It contains original
instructions, references, templates, and reviewer cases for teaching and
applying Frontier Infra standards. It does not vendor source code from the
upstream project repositories.

The plugin references these public Frontier Infra projects by name and URL as

notices, and contribution histories remain in their own repositories.

Do not copy source, examples, assets, or generated receipts from an upstream
repository into this plugin unless that material has a complete license notice,
has been allowlist-audited for public release, and is listed here.
